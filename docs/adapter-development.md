# Adapter development rules

Adapter는 외부 애플리케이션 연동을 미리보기와 분리하는 경계입니다. 인터페이스를 구현했다는 사실만으로 실행 권한이나 안전 승인이 생기지는 않습니다.

## 현재 Adapter

- `PreviewAdapter`: React 미리보기만 렌더링하며 외부 프로세스 권한이 없습니다.
- `OfficialCodexAdapter`: 공식 외부 적용 API가 확인되지 않아 기능이 비활성화되어 있습니다.
- `AppServerClientAdapter`: 향후 독립 Codex 클라이언트를 검토할 때만 사용하는 경계입니다.

## 새 Adapter의 필수 조건

1. 공식 문서와 지원 버전을 ADR에 기록합니다.
2. 읽기, 적용, 복원 권한을 capability로 분리합니다.
3. 적용 전에 원래 상태를 안전하게 보존하고 공식 인터페이스로 복원할 수 있어야 합니다.
4. 한 번의 명시적인 사용자 동작에 한 번만 실행합니다.
5. 짧은 타임아웃 뒤 중단하며 자동 재시도하지 않습니다.
6. 비밀번호, 토큰, 쿠키, 계정·채팅 데이터를 읽거나 로그에 남기지 않습니다.
7. 실패 조건과 업데이트 호환성 위험을 테스트와 문서에 포함합니다.

## 허용하지 않는 구현

- 프로세스 종료, 반복 재시작, 새 창 반복 생성
- DOM/CSS 주입과 Electron 원격 디버깅 연결
- Microsoft Store 패키지나 설치 파일 수정
- `.codex`, `AGENTS.md`, 로그인·채팅 데이터 접근
- 외부 주소에 제어 포트 공개

공식 지원 여부가 불분명하면 capability를 `false`로 유지합니다.
