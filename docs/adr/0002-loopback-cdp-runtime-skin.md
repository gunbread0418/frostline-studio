# ADR-0002: Experimental loopback CDP runtime skin

- Status: Accepted for manual M3 sessions
- Date: 2026-08-13
- Scope: M3 manual initial apply, same-session live update and restore

## Context

공식 Codex Appearance에는 색상과 글꼴 설정이 있지만 사진 배경을 외부 프로그램에서 적용하는 공개 API는 확인되지 않았습니다. 사용자는 이 제한을 이해한 뒤, 설치 파일이나 사용자 데이터는 수정하지 않으면서 현재 실행 화면에 사진을 적용할 수 있는 비공식 방법을 명시적으로 요청하고 다음 안전 조건을 승인했습니다.

- 사용자가 Codex를 직접 정상 종료합니다.
- Frostline Studio는 Codex를 강제 종료하거나 반복 실행하지 않습니다.
- 연결은 `127.0.0.1`에만 열고 짧은 타임아웃을 사용합니다.
- 한 번 실패하면 자동 재시도하지 않습니다.
- 패키지, 설치 파일, `.codex`, `AGENTS.md`, 로그인·채팅 데이터는 수정하지 않습니다.

## Decision

1. `OfficialCodexAdapter`는 M3의 수동 적용과 복원만 제공합니다. 자동 적용 capability는 계속 `false`입니다.
2. 실행 중인 Codex가 있으면 확인한 AUMID만 세션에 저장하고 적용을 중단합니다. 앱을 닫는 기능은 구현하지 않습니다.
3. 사용자가 Codex를 종료하고 다시 적용을 누르면 Windows `IApplicationActivationManager`로 확인된 AUMID를 한 번 실행합니다. 인수는 loopback 주소와 무작위 CDP 포트뿐입니다.
4. Windows TCP 테이블에서 포트 소유자의 AUMID가 앞서 확인한 Codex와 같은지 검증합니다.
5. CDP 대상은 URL이 정확히 `app://-/index.html`인 page 하나만 허용합니다.
6. 채팅 내용은 읽지 않고 문서 루트, Electron 창 유형과 알려진 표면 선택자 개수만 확인하는 호환성 프로필을 통과해야 합니다.
7. 선택한 관리 사진을 data URL로 만들고 명시적인 `<div><img>` 레이어와 공통 테마 토큰 CSS를 고유 ID로 주입합니다.
8. 적용 성공은 고유 표식, 이미지 디코딩, 자연 크기, DOM 연결, 화면 크기와 `pointer-events: none`을 같은 명령의 결과로 확인합니다.
9. 활성 세션의 라이브 갱신은 같은 target ID와 표식을 재검증한 뒤 기존 레이어만 교체합니다. 새 Codex 프로세스나 새 포트를 만들지 않습니다.
10. 라이브 갱신이 실패하면 이전 정상 레이어를 유지하고 UI의 라이브 연결을 잠급니다. 사용자가 수동 재연결을 누르기 전에는 다음 시도를 하지 않습니다.
11. 복원은 고유 표식이 일치할 때 Frostline style과 레이어만 제거합니다. 원래 앱 파일이나 설정은 건드리지 않습니다.
12. 모든 단계에는 제한 시간이 있으며 실패 후 반복 폴링이나 자동 재시도를 하지 않습니다. 수동 재시도는 사용자가 버튼을 다시 누른 경우에만 시작합니다.

## Security and compatibility risks

- CDP는 인증이 없는 로컬 디버깅 인터페이스입니다. loopback과 무작위 포트로 노출 범위를 줄이지만 같은 사용자 권한의 악성 로컬 프로그램까지 차단하지는 못합니다.
- Codex가 실행되는 동안 CDP 포트가 유지됩니다. 사용을 마치면 Codex를 정상 종료해야 포트가 닫힙니다.
- 앱 업데이트로 AUMID, 실행 인수 처리, 대상 URL, DOM 또는 CSS가 바뀌면 적용이나 복원이 실패할 수 있습니다.
- 런타임 스타일은 프로세스 메모리에만 있으므로 Codex를 종료하면 사라집니다.
- 일부 스타일만 적용되는 실패 가능성을 줄이기 위해 적용 직후 확인하고, 실패 시 같은 세션에서 Frostline style 제거를 한 번 시도합니다. 이 제거 시도는 적용 재시도가 아닙니다.

## Rejected alternatives

- 강제 종료와 재실행: 사용자 데이터 손실 위험과 명시된 금지 규칙 때문에 제외합니다.
- `app.asar`, Store 패키지, 설치 파일 수정: 서명과 업데이트 무결성을 훼손하므로 제외합니다.
- `.codex`나 내부 상태 파일 수정: 계정·대화 데이터 경계를 침범할 수 있어 제외합니다.
- 주기적 폴링과 자동 재시도: 같은 실패를 반복할 수 있어 M3에서 제외합니다.
- 다른 테마 프로그램의 호출 또는 코드·이미지 복사: 독립성과 라이선스 경계를 위해 제외합니다.

## Validation target

첫 수동 검증 대상인 Windows Store Codex `26.803.10989.0`에서 이전 구현의 실제 사진 적용과 복원은 사용자가 확인했습니다. 그 과정에서 첫 적용 판정의 간헐적 실패와 입력 커서 가독성 문제를 발견했습니다. 이번 명시적 이미지 레이어, 공통 토큰과 라이브 갱신 수정본은 같은 버전에서 회귀 검증하기 전까지 완료로 표시하지 않습니다.
