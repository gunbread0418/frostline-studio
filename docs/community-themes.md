# Community theme guide

커뮤니티 테마는 코드 변경 없이 Frostline Studio의 색상 조합을 공유하는 방법입니다.

## 만드는 방법

1. Frostline Studio에서 색상과 배경 효과를 조절합니다.
2. 접근성 대비 검사에서 강조색과 주요 표면의 결과를 확인합니다.
3. 공개할 테마에는 개인 사진을 제거하거나 재배포 권한이 있는 사진만 사용합니다.
4. `내보내기`로 파일을 만들고 공개 전에 JSON 내용을 확인합니다.
5. Schema와 예시 파일을 기준으로 형식을 검증합니다.

## Pull request에 포함할 내용

- `examples/` 아래의 테마 JSON
- 테마의 목적과 권장 사용 환경
- 이미지가 있다면 제작자, 출처, 재배포 라이선스
- 대비 검사 결과

저장소에서 제공하는 예시 테마는 프로젝트가 직접 만든 색상 값만 사용하며 사진을 포함하지 않습니다.

## 금지 사항

- 개인 사진, 계정 화면, 채팅 내용이 포함된 이미지
- 재배포 권한을 확인할 수 없는 배경 이미지
- OpenAI나 다른 회사의 공식 테마로 오인할 수 있는 이름과 설명
- 공식 Codex 앱의 내부 수정이나 런타임 주입을 요구하는 설치 절차
