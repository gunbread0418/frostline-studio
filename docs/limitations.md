# Known limitations

## M1 범위

- 미리보기는 Codex에서 영감을 받은 독립 UI이며 실제 Codex 화면을 복제하거나 수정하지 않습니다.
- 실제 Codex 적용과 복원 버튼은 비활성 상태로 표시됩니다.
- Windows 자동 시작과 프로세스 이벤트 감지는 구현하지 않습니다.
- Windows 설치 파일과 코드 서명은 M5 범위입니다.
- 가져오기 파일은 Frostline Studio JSON 형식만 지원합니다.
- 앱 전용 데이터 폴더에서 참조되지 않는 이미지 정리는 저장 성공 뒤에만 수행합니다.

## M2에서 확인한 공식 지원 범위

- Codex 앱의 `Settings → Appearance`는 기본 테마, 강조색, 배경색, 전경색, UI 글꼴, 코드 글꼴과 사용자 테마 공유를 지원합니다.
- 공식 Appearance 문서에는 사진이나 이미지 배경 기능이 설명되어 있지 않습니다.
- 공식 설정 참조에서 확인되는 `tui.theme`은 터미널 UI의 구문 강조 테마이며 데스크톱 앱 사진 배경 설정이 아닙니다.
- 공식 App Server는 인증, 대화 기록, 승인, 이벤트 스트리밍 같은 독립 클라이언트 기능을 제공합니다. 공식 데스크톱 앱의 UI 스타일을 변경하는 API로 문서화되어 있지 않습니다.
- 외부 프로그램이 공식 데스크톱 앱의 테마를 가져오거나 적용하거나 복원하는 공식 API는 확인되지 않았습니다.

문서에 없다는 사실만으로 내부 구현까지 절대 불가능하다고 단정할 수는 없습니다. 다만 공개 포트폴리오에서 지원 가능한 기능으로 표시할 근거가 없으므로 현재는 적용 기능을 구현하지 않습니다. DOM/CSS 주입, 원격 디버깅 연결, 패키지 수정, 내부 상태 파일 수정은 공식 지원이 아니며 안전·업데이트 호환성 기준을 충족하지 못해 채택하지 않습니다.

자세한 조사 범위와 로컬 확인 결과는 [M2 연동 가능성 조사](integration-research.md), 결정 근거는 [ADR-0001](adr/0001-codex-integration-boundary.md)에 기록했습니다.

## 라이선스와 공개

프로젝트 라이선스는 아직 선택하지 않았습니다. GitHub 공개 저장소 생성과 push도 로컬 MVP 검증 및 사용자 최종 확인 전에는 수행하지 않습니다.
