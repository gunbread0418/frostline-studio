# Known limitations

## 제품 범위

- 미리보기는 Codex에서 영감을 받은 독립 UI입니다.
- 실제 Codex 적용과 복원은 사용자가 승인한 실험적 M3 기능입니다. 공식 OpenAI API가 아닙니다.
- 실행 중인 Codex가 있으면 사용자가 직접 정상 종료해야 하며 Frostline Studio는 강제로 닫지 않습니다.
- 스타일은 현재 실행 중인 Renderer 메모리에만 존재하므로 Codex를 종료하면 사라집니다.
- Codex 업데이트로 앱 ID, 실행 인수, 대상 URL, DOM 또는 CSS 구조가 바뀌면 동작하지 않을 수 있습니다.
- 적용 전 호환성 프로필은 루트, 창 유형과 알려진 선택자 개수만 확인합니다. 사용자 채팅 문자열은 읽지 않지만 이후 Codex 업데이트의 모든 UI 변경을 예측할 수는 없습니다.
- 미리보기와 실제 적용은 같은 테마 토큰을 사용하지만 Codex 자체 레이아웃과 컴포넌트까지 복제하지 않으므로 픽셀 단위로 같지는 않습니다.
- 라이브 갱신은 현재 검증된 세션에서만 동작합니다. 한 번 실패하면 이전 정상 화면을 유지하고 자동 갱신을 잠그며 사용자가 수동으로 다시 연결해야 합니다.
- CDP가 열린 동안 같은 Windows 사용자 권한의 다른 로컬 프로그램이 디버깅 포트에 접근할 가능성을 완전히 없앨 수 없습니다.
- Windows 자동 시작과 프로세스 이벤트 감지는 구현하지 않습니다.
- Windows x64 NSIS 설치 파일은 제공하지만 ARM64 설치 파일과 Microsoft Store 패키지는 제공하지 않습니다.
- 설치 파일은 코드 서명되지 않았으므로 Windows SmartScreen이 게시자를 확인할 수 없다는 경고를 표시할 수 있습니다.
- 제거 프로그램은 사용자 사진과 테마가 들어 있는 앱 전용 데이터를 자동 삭제하지 않습니다. 완전 삭제가 필요하면 사용자가 앱 전용 데이터 폴더를 별도로 정리해야 합니다.
- 가져오기 파일은 Frostline Studio JSON 형식만 지원합니다.
- 앱 전용 데이터 폴더에서 참조되지 않는 이미지 정리는 저장 성공 뒤에만 수행합니다.
- 접근성 검사는 본문·보조·입력·링크·입력 커서 색상의 WCAG 대비를 참고값으로 보여 줍니다. 투명 표면 뒤 사진의 모든 픽셀이나 전체 UI 접근성 인증을 의미하지 않습니다.
- Appearance 가이드는 색상값을 클립보드에 복사할 뿐 공식 Codex 앱을 자동으로 변경하지 않습니다.

## M2에서 확인한 공식 지원 범위

- Codex 앱의 `Settings → Appearance`는 기본 테마, 강조색, 배경색, 전경색, UI 글꼴, 코드 글꼴과 사용자 테마 공유를 지원합니다.
- 공식 Appearance 문서에는 사진이나 이미지 배경 기능이 설명되어 있지 않습니다.
- 공식 설정 참조에서 확인되는 `tui.theme`은 터미널 UI의 구문 강조 테마이며 데스크톱 앱 사진 배경 설정이 아닙니다.
- 공식 App Server는 인증, 대화 기록, 승인, 이벤트 스트리밍 같은 독립 클라이언트 기능을 제공합니다. 공식 데스크톱 앱의 UI 스타일을 변경하는 API로 문서화되어 있지 않습니다.
- 외부 프로그램이 공식 데스크톱 앱의 테마를 가져오거나 적용하거나 복원하는 공식 API는 확인되지 않았습니다.

문서에 없다는 사실만으로 내부 구현까지 절대 불가능하다고 단정할 수는 없습니다. M3는 이 한계를 분명히 표시한 실험적 기능이며, DOM/CSS 런타임 주입과 CDP 연결을 사용합니다. 패키지 수정과 내부 상태 파일 수정은 계속 금지합니다. 현재 확인 대상은 Windows Store Codex `26.803.10989.0`이며 다른 버전의 성공을 보장하지 않습니다.

자세한 조사 범위와 로컬 확인 결과는 [M2 연동 가능성 조사](integration-research.md), M3 결정과 위험은 [ADR-0002](adr/0002-loopback-cdp-runtime-skin.md)에 기록했습니다.
