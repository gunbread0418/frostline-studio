# Frostline Studio v0.1.0 — Preview MVP

첫 공개 프리릴리스입니다. Windows에서 로컬 사진과 색상으로 테마를 만들고 독립 미리보기에서 확인할 수 있습니다.

## 포함된 기능

- 사진을 앱 전용 데이터 폴더로 복사
- 배경 위치·크기·효과와 표면 색상 편집
- 여러 테마 저장, 복제, 삭제, 가져오기와 내보내기
- 앱 재실행 뒤 설정 복구
- 접근성 대비 검사와 공식 Appearance용 수동 색상 가이드
- 공개 테마 Schema와 사진 없는 예시 테마

## 안전 범위

이 버전은 실제 Codex 앱에 테마를 적용하지 않습니다. Codex 프로세스, 설치 파일, `.codex`, 로그인·채팅 데이터에 접근하지 않습니다.

## 설치 상태

이 프리릴리스에는 Windows 설치 파일이 없습니다. 저장소를 clone한 뒤 README의 개발 실행 방법을 사용합니다. 패키징과 코드 서명은 이후 마일스톤입니다.
