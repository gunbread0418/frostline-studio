# Frostline Studio v0.2.0 — Windows Preview Installer

Windows 사용자가 소스 빌드 없이 설치할 수 있는 첫 패키징 프리릴리스입니다. 앱의 제품 범위는 v0.1.0과 같이 안전한 독립 테마 미리보기입니다.

## 설치 파일

- `Frostline-Studio-0.2.0-Setup-x64.exe`: Windows 10 이상 x64용 현재 사용자 설치 프로그램
- `Frostline-Studio-0.2.0-Setup-x64.exe.blockmap`: 향후 업데이트 전송을 위한 블록 정보
- `SHA256SUMS.txt`: 공개 산출물의 SHA-256 체크섬

설치 파일은 관리자 권한을 요구하지 않습니다. 제거해도 앱 전용 테마와 사진 데이터는 자동으로 삭제되지 않습니다.

## 검증한 범위

- lint, TypeScript 검사, 5개 파일의 테스트 16개, production build
- Electron 재실행 뒤 설정 복구
- `app.asar` 허용 목록과 개인정보·비밀정보 패턴 검사
- 임시 경로 설치, 설치된 실행 파일의 재실행 복구, 자동 제거
- 공개 산출물 SHA-256 생성

## 서명 상태

이 프리릴리스는 코드 서명 인증서로 서명되지 않았습니다. Windows SmartScreen이 알 수 없는 게시자 경고를 표시할 수 있습니다. 설치 전 GitHub 저장소의 공식 Release에서 내려받았는지 확인하고 `SHA256SUMS.txt`와 파일 해시를 비교하세요.

```powershell
Get-FileHash .\Frostline-Studio-0.2.0-Setup-x64.exe -Algorithm SHA256
```

## 안전 범위

이 버전은 실제 Codex 앱에 테마를 적용하지 않습니다. Codex 프로세스, 설치 파일, `.codex`, 로그인·채팅 데이터에 접근하지 않습니다. 공식 외부 테마 적용 API가 확인되지 않았으므로 M3과 M4는 구현하지 않았습니다.
